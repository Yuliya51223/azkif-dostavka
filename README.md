# АЗКиФ · Доставка

Сайт расчёта стоимости доставки для менеджеров АЗКиФ (Анапский завод кровли и фасада, склад: г. Волгоград, ул. Ясноморская, 2).

Менеджер вписывает адрес клиента и выбирает машину — сайт выдаёт цену по прайсу. Адреса вне прайса уходят логисту на согласование. Логист ведёт тарифы и согласует цены.

Разработка: Тёмина Юлия.

## Запуск

Статический сайт без сборки и зависимостей. Откройте `index.html` в браузере
(или раздайте папку любым веб-сервером, например `python3 -m http.server`).

## Вкладки

| Вкладка | Для кого | Что делает |
|---|---|---|
| Расчёт | менеджер | адрес + Газель/Газон → цена; запрос логисту, если адреса нет в прайсе; «Мои запросы» |
| Согласование | логист | ответ на запросы: цена, комментарий, утвердить/отказать, добавить пункт в тарифы |
| Рейс | логист | калькулятор сборных заказов: формат рейса, тип отклонения, км, статус |
| Тарифы | логист | ставка за км, шаг округления, порог; пункты прайса — изменить, добавить, удалить, пересчитать |
| Правила | все | принцип расчёта, правила, схема Ростовского направления |

## Правила расчёта

- Адрес из прайса — фиксированная цена.
- Адрес вне прайса (кроме Волгограда) — тариф ближайшего пункта + 60 ₽ за 1 км в одну сторону, округление вверх до 100 ₽; цена предварительная, подтверждает логист.
- Волгоград — только фиксированные тарифы, доплата за км не применяется.
- Газель — до 2 т, до 6 м; Газон — до 5 т, до 7,5 м.

## Структура

```
index.html        разметка всех вкладок
css/style.css     оформление (в стиле сайта фасонных изделий АЗКиФ)
js/app.js         логика: распознавание адреса, расчёт, согласование, рейс, тарифы
js/local-db.js    локальное хранилище данных в браузере (localStorage)
js/data.js        исходные данные: 231 пункт прайса, настройки, журнал запросов
img/logo.svg      логотип
ИНСТРУКЦИЯ.txt    инструкция для пользователей
```

## Данные

Источник — таблица «АЗКиФ — Калькулятор доставки по адресу» и прайс-лист.
231 пункт: 159 утверждённых с ценами, 72 «На проверке» (без цен, менеджеру не показываются).

## Ограничения текущей версии

- Данные хранятся в браузере одного компьютера (`js/local-db.js`). Для общей работы менеджеров и логиста нужен сервер с общей базой — `local-db.js` заменяется подключением к ней, остальной код не меняется.
- Автоматический подбор ближайшей точки и расстояния для адресов вне прайса требует сервера с доступом к картам; без него такие адреса уходят логисту.
